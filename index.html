Release Notes

What's New in SE16

1. Perfect Geometry Top Dock

Sistem navigasi bawah (Bottom Dock) resmi digantikan oleh Top Dock Perfect Geometry. Didesain secara presisi matematis menggunakan clip-path polygon membentuk pola |___\ \______/ /___| yang menyatu sempurna. Dilengkapi efek bayangan terpisah (Z-Index layering) untuk kesan 3D ekstrem.

2. Shinko Cache 4.0 & Auto-Fix

Mesin FPS Optimizer kini jauh lebih cerdas (Versi 4.0). Transisi penyesuaian render saat perangkat panas (thermal throttling) kini menggunakan smooth interpolator sehingga tidak ada lagi kedipan visual. Auto-Fix interceptor tetap memantau JavaScript runtime secara diam-diam di background.

3. iOS/MacOS System Diagnostics

Halaman System Status telah dirombak total menjadi panel diagnostik yang mereplika gaya "About Phone/Mac" milik Apple. Menyediakan parameter langsung (Live Check) ke server utama ASNF Repo.
