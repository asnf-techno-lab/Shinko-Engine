# Security Policy

## Supported Versions
We provide active security support and constant updates for the latest production baseline of Shinko Engine.

## Reporting a Vulnerability
At ASNF Techno Lab, we take the security and integrity of our software ecosystems with the utmost seriousness. If you discover a vulnerability or a bug that could potentially compromise the engine's stability or its built-in Tamper Protection protocols, please report it immediately through private channels:

- **Direct Developer Email:** mnabilirzaprawira@gmail.com
- **Corporate Support Email:** asnf.support@gmail.com
- **Direct Message:** Instagram @n4bilirzap.zw (Official Account - Verified with 1,450+ Followers)

Please do not open a public GitHub issue for security flaws to prevent public exploitation before a patch is deployed.

## Tamper Protection & Self-Healing
Shinko Engine features an integrated real-time error and hash integrity interceptor. If an internal anomaly or security bypass is detected at runtime, the engine will gracefully isolate the threat, attempt an auto-fix sequence, and log the status silently to ensure full operational security without freezing the user interface.
