# Contributing to Shinko Engine

First of all, thank you for your interest in helping us optimize the **Shinko Engine** ecosystem! We are fully committed to making this core the absolute pinnacle of fluid tech design, and we will **continually update and upgrade** it to bring you the best possible framework.

## Proprietary Notice
Because Shinko Engine is distributed under a strict Exclusive Proprietary License, you **cannot directly fork, copy, or submit pull requests modifying the absolute core engine structures** without explicit approval from the Chief Architect.

## How to Contribute Right Now

### 1. Bug Reporting & Diagnostics
If you find a frame drop on a specific hardware specification, or an overlap bug in our CSS Fluid Grid system:
- Open a GitHub issue detailing your device configuration (e.g., screen refresh rate, chipset architecture).
- Provide exact reproduction steps so the engineering team can address it in the next update cycle.

### 2. UI/UX Suggestions
Have an elegant animation curves configuration or a unique glassmorphism specular highlight property idea? 
- Discuss it with the Founder directly via Instagram DM (`@n4bilirzap.zw`).
- Approved concepts will be securely integrated into the main branch with proper credits added to the documentation archives.

### 3. Hardware Optimization Testing
You can apply to become an official tester for experimental root performance modules (such as AIOG or Magic Random Pro variants) by following the verification protocols outlined in the `SUPPORT.md` file.

Join us in shaping the future of elite software aesthetics!
